# Telephone-format source notes

The supplied Nigeria-format numbers are displayed exactly as received. The `tel:` links use `+234` and omit the domestic trunk prefix `0`. The Nigerian Communications Commission defines country code 234 and says an international number contains the country code and the national number, not the trunk prefix [1]. Its mobile-number allocation table lists prefixes `0814` and `0916` [2]. The links use `+2348142695560` and `+2349169117749`; allocation records do not establish the current provider of an individual subscriber, especially if ported.

The supplied Ghana number already includes `+233`. The National Communications Authority's published numbering plan states that Ghana's country code is `+233` and the national significant number has nine digits [3]. The supplied `25 669 6916` has nine digits after the country code. The NCA document labels the `25` range as mobile broadband; it does not establish WhatsApp availability or confirm voice capability for this specific subscriber. No WhatsApp links are published.
